# Contextual model request v2

`contextual-request.json` and its JSON schema are shared by Java and Python tests. The result fixture
retains the v1 response format (claims cite global chunk IDs). The v2 request contains:

- `schemaVersion: "2.0"`;
- the unchanged v1 `request` with explicit text evidence and the `grounded-response:2` template;
- `context`: escaped, labeled JSON blocks and a versioned summary/budget/key mapping.

The summary is persisted in the public response without context text. Each source retains its own
key/location when exact text is shared. The model emits `citationKeys`; the worker maps validated
keys to chunk IDs. Hashes, framing, contents, duplicate references and budget arithmetic are also
validated in code. See [grounded-context.md](../../../docs/development/grounded-context.md).

The schema is generated by `ContextualRequest.model_json_schema(by_alias=True)` from
`researchhub_worker.ai.context`, with the JSON Schema 2020-12 dialect declared. Keep the old v1
fixtures/template immutable for compatibility tests.
