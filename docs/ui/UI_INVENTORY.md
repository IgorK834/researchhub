# UI inventory

Complete inventory of the ResearchHub design reference mapped to the repository as of this audit. Generated from one data set together with [`UI_BACKLOG.md`](UI_BACKLOG.md), [`UI_DEPENDENCIES.md`](UI_DEPENDENCIES.md) and [`issues.json`](issues.json); issue conventions are in [`ISSUE_STYLE_GUIDE.md`](ISSUE_STYLE_GUIDE.md).

**No production code was modified and no GitHub issue was created.** `gh` was used read-only.

## How to read this

### Readiness classes

| Class | Meaning |
| --- | --- |
| `DONE` | Implemented, working and sufficiently matching the design. |
| `EXISTS_NEEDS_POLISH` | Functionality and UI exist; bring them in line with the design system. |
| `READY_NOW` | Contracts and behavior exist; the UI can be built completely now. |
| `UI_ONLY_NOW` | Underlying feature is incomplete, but a stable presentational component or contract can be built without inventing business logic. |
| `BLOCKED` | Do not build yet: an important dependency or product contract is missing or unstable (blocker named). |
| `NEEDS_DESIGN_DECISION` | Behavior or design is ambiguous; implementing would be guessing. |

No item is classified `DONE`: nothing in the repository is styled at all (see the baseline below), so every existing feature at best `EXISTS_NEEDS_POLISH`.

## Design coverage gaps (code that has no design)

These are implemented and tested features with no screen or component in any PDF. The audit classifies them `EXISTS_NEEDS_POLISH` and proposes restyling them **only with shared primitives**, not with invented layouts. Confirm placement with the designer when convenient.

- Source version history, replace-source form and citation version status (`SourceVersionHistory`, `SourceReplaceForm`, `CitationVersionStatus`; RH-130).
- Extraction preview (text/structure per page or sheet), CSV asset profile and processing history (`SourceExtractionPreview`, `CsvAssetProfile`, `SourceProcessing`).
- Dataset preview version selector and limit/estimate warnings (`DatasetPreviewPanel`) — the design shows a simpler viewer without versions.
- Research conversation picker and "New conversation" in the editor aside (`ResearchPanel`) — the design has an Investigations list on a dedicated page.
- Authoring "Clarify" and "Fix grammar" rewrite actions (the design shows Improve, Shorten, Expand, Explain only).
- Not-found pages for workspace, document, source and the global route (deliberately neutral, non-enumerating copy).
- Archived-document and archived-workspace notices.
- API health banner (`ApiStatusBanner`, scaffolding).
